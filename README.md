Mimi the Dog — это уютный кликер от создателя Homka, вдохновлённый творчеством @crispytyph. Кликайте на Мими, прокачивайте прогресс и открывайте новых персонажей!
Что ждёт в игре:
• 23 уникальных Мими — открывайте их одного за другим, продвигаясь по этапам.
• Смена тем — разблокируйте новое оформление по мере прохождения.
• Магазин улучшений — покупайте апгрейды, чтобы кликать ещё эффективнее.
• Коллекции и достижения — собирайте полный набор и выполняйте игровые цели.
• Система сохранений — ваш прогресс никуда не пропадёт.
